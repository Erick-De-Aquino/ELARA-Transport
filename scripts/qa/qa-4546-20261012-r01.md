## Herramienta y modos

Requiere **psql compatible con PostgreSQL 17**, conexión de sesión (host directo
o pooler session), y archivo -f. No usar pooler transaction: el paquete depende
de GUC y advisory lock de sesión. No usar -1/--single-transaction, BEGIN externo,
SQL Editor que envuelva todo, Supabase CLI para ejecutar este archivo, ni MCP
para pegarlo entero. Incluye metacomandos psql.

El DO de PREPARE es de nivel superior: COMMIT del bootstrap y COMMIT por caso.
PostgreSQL inicia la siguiente transacción automáticamente. No hay handlers
EXCEPTION ni subtransacciones rodeando COMMIT. Error revierte el caso vigente,
ON_ERROR_STOP detiene psql y los casos ya confirmados se conservan. No hay
cleanup, reparación o continuación automática.

Referencia del control transaccional:
[PostgreSQL 17 — PL/pgSQL transactions](https://www.postgresql.org/docs/17/plpgsql-transactions.html).
Variables/condicionales:
[PostgreSQL 17 — psql](https://www.postgresql.org/docs/17/app-psql.html).

Por defecto QA_MODE=PREFLIGHT, ALLOW_PREPARE=false.
ALLOW_PREVIEW=true y ALLOW_GENERATE=true son asignaciones incondicionales.
GENERATE se ejecutó y pasó; los flags conservados documentan el mecanismo, no autorizan repetirlo.
-v no sobrescribe estos valores; GENERATE sigue requiriendo la confirmación adicional exacta.
GENERATE además exige CONFIRM_GENERATE=QA-4546-20261012-R01:GENERATE.
PREPARE exige ALLOW_PREPARE=true y CONFIRM_PREPARE=QA-4546-20261012-R01:PREPARE.
