# Proyecto Atlas — Principios del Proyecto

## 1. Identidad del proyecto

Proyecto Atlas es el nombre interno de desarrollo de ELARA Transport.

ELARA Transport es la división de ELARA dedicada al transporte privado de pasajeros mediante reserva previa.

## 2. Roles de trabajo

- Fundador / Product Owner: define visión, prioridades y reglas del negocio.
- Arquitecto: convierte la visión en estructura, documentación y decisiones técnicas.
- Codex: implementa código siguiendo la documentación aprobada.
- GitHub: almacena el proyecto y su historial.
- VS Code: entorno principal de trabajo.

## 3. Regla principal

Codex no tomará decisiones de arquitectura.

Codex solo implementará lo definido en la documentación aprobada.

## 4. Método ABE

ABE significa Arquitectura Base Erick.

También se usará como método de trabajo:

- Analizar.
- Base.
- Ejecutar.

Primero se entiende el problema, luego se diseña la solución y solo después se escribe código.

## 5. Principios técnicos

- Arquitectura antes que rapidez.
- Código limpio.
- Responsabilidad única por archivo.
- No duplicar lógica.
- No mezclar módulos.
- No crear funcionalidades sin regla de negocio definida.
- No añadir complejidad innecesaria.
- Toda decisión importante debe documentarse.
- Todo cambio debe ser escalable y mantenible.

## 6. Principio MVP

La primera versión debe resolver la operación real de ELARA Transport sin intentar construir toda la visión futura.

El sistema debe estar preparado para crecer, pero centrado en el presente.

## 7. Estado actual

Versión del proyecto: 0.1.0  
Estado: Documentación y arquitectura inicial.
